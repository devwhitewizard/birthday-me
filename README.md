# Birthday Surprise Web Application

A beautiful, cinematic, and interactive web application designed to celebrate a special birthday. The app features a series of animated sections including a timeline of memories, a moodboard, interactive elements like a chaos meter and heart-hold transition, and a personal secret letter.

## ✨ Features

- **Animated Hero Section**: A glowing, romantic introduction.
- **Cinematic Transitions**: Smooth, high-end transitions between stages of the experience.
- **Interactive Chaos Meter**: A fun, interactive bar that measures the "chaos" level.
- **Memory Gallery**: A collection of beautiful moments captured in a stylish collage.
- **Secret Letter**: A personal message hidden behind an interactive envelope.
- **Forever Counter**: A real-time counter showing the time spent together.

## 🛠️ Technologies Used

### **Core Stack**
- **[React 19](https://react.dev/)**: The latest version of React for high-performance UI rendering.
- **[Vite](https://vitejs.dev/)**: A blazing fast frontend build tool and development server.
- **[TypeScript](https://www.typescriptlang.org/)**: Ensures type safety and improves developer experience.

### **Styling & UI**
- **[Tailwind CSS](https://tailwindcss.com/)**: Utility-first CSS framework for rapid and consistent styling.
- **[Framer Motion](https://www.framer.com/motion/)**: For complex, hardware-accelerated animations and page transitions.
- **[Lucide React](https://lucide.dev/)**: A beautiful, consistent icon library for the UI.
- **[Radix UI](https://www.radix-ui.com/)**: Headless UI primitives for building accessible and high-quality components.

### **Animation & Interaction**
- **[PostCSS](https://postcss.org/)** & **[Autoprefixer](https://github.com/postcss/autoprefixer)**: For modern CSS processing and cross-browser compatibility.
- **[clsx](https://github.com/lukeed/clsx)** & **[tailwind-merge](https://github.com/dcastil/tailwind-merge)**: For dynamic and conflict-free CSS class management.

### **Infrastructure & Tools**
- **[React Router](https://reactrouter.com/)**: For efficient client-side routing.
- **[TanStack Query](https://tanstack.com/query/latest)**: For state management and data fetching patterns.
- **[Zod](https://zod.dev/)**: For robust schema validation and type inference.

## 🚀 Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run the development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```
